# Doom timedemo results

Generated by `tools/timedemo_report.py` from the files `scripts/timedemo.sh` writes to
`build/results/`. Every run plays a recorded demo with `-timedemo`, dumps every frame the
program presents, and compares the dump pixel for pixel (after palette lookup) with the
dump of native doomgeneric built from the same patched sources.

Reproduce one row: `make timedemo ENGINE=accurate DEMO=demo3`. Clock: 50 MHz.
